<Typography variant="body2" gutterBottom>
  QAGS uses questions and answers to help assess factual consistency and
  missing information in generated text, such as a summary or clinical note.
  It generates questions from both the evaluated text and a comparison text,
  answers each question using each text, and compares the answers. Disagreements
  can point to contradictions, unsupported details or omissions for review.
</Typography>

<Typography variant="body2" gutterBottom>
  The comparison text can be a source document or a reference answer, selected
  through the prompts. Choose it carefully: agreement with a reference answer
  does not establish that the answer is itself faithful to the original source.
  Reviewing the questions and answers helps explain individual scores.
</Typography>

<Typography variant="subtitle1" gutterBottom>
  Evaluation modes
</Typography>

<Typography variant="body2" component="div">
  <ReactMarkdown>{`
- **Ternary mode:** Uses yes/no/unknown questions, making answer comparisons straightforward. It reports accuracy, coverage and groundedness. The last two focus on matching yes answers and depend on question wording; correctly preserved negative facts may not contribute.
- **Exact match mode:** Compares open-ended answers as text. It is useful when an answer has a clear expected form, but can penalise equivalent wording.
- **Judge mode:** Uses an LLM to compare open-ended answers by meaning. It is more flexible about wording but requires additional model calls and depends on the judge's reliability.
  `}</ReactMarkdown>
</Typography>

<Typography variant="body2" gutterBottom>
  This can be useful for checking factual content in summarisation and other
  open-ended tasks. It requires many model calls, and results depend on the
  questions, prompts and evaluator model. Matching unknown answers does not
  establish factual support. Invalid answers fail evaluation rather than being
  counted as agreement, so review failures alongside scores. These scores are
  aids to evaluation, not verified fractions of facts or proof of clinical safety.
</Typography>
